<h3 align="center">🧟 About The Game 🧟</h3>

<br/>

** Jack's Escape: Jodhpur Zombie Outbreak ** is an adrenaline-fueled, action-packed 2D endless survival runner game set against the iconic backdrop of Jodhpur (The Blue City).

A sudden zombie apocalypse has overrun the ancient fortress alleys and rooftop corridors. Take control of Jack, dodge relentless undead hordes, leap across treacherous obstacles, and run for survival in a high-stakes race where quick reflexes make all the difference!

<br/>

---

<h3 align="center">⚡ Key Features ⚡</h3>

<br/>

- 🏃 Fast-Paced Survival Mechanics:  Fluid jumping, sliding, and obstacle avoidance controls.
- 🌆 Atmospheric Themed Environments:  Run through the stylized alleys and rooftop landscapes of the Blue City.
- ⚡ Dynamic Speed Scaling:  Experience increasing difficulty and faster gameplay as your score climbs.
- 🎮 Smooth HTML5 Canvas Performance:  Crisp 60 FPS sprite animations and collision detection.
- 🚀 Instant Browser Playability:  No downloads or plugins required—launch and play directly in any browser.
